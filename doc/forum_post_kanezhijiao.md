## 【工具发布】D2R Multi —— 暗黑2重制版 多开/多账号管理器（开源/绿色单文件/中文）

各位D2R的朋友好，

多账号党的痛大家都懂：**切个号要重登战网、开双开要折腾句柄、路径还经常串**。我把整套流程做成了一个工具——**D2R Multi**，一键切号、一键多开、一键序列拉起全部账号。开源、免安装、单文件绿色版，Rust 编写、原生性能。

〔图：01-overview.jpg —— 主界面〕

### ✨ 它能干什么

- 🔁 **多账号免重登**：每个战网账号只登一次，之后一键启动，长期免登录、互不串号
- 🎮 **同机多开**：自动清理 D2R 实例锁，一台电脑同时跑多个 D2R
- 🚀 **序列启动**：把启动顺序存成预设，点一下按队列把所有号依次拉起来
- 🧰 **手动工具箱**：句柄查看器/权限修复/环境诊断，自动化搞不定的边角自己动手
- 🌏 **5 种语言** / 3 套主题 / 深色 UI

### 🧠 原理一句话

每个账号绑一个独立的 **Windows 本地用户**（战网登录态天然按用户隔离），启动时自动切换战网的 `product.db` 路径快照 + 关闭 D2R 的防多开锁，再以目标用户身份拉起战网。**不改游戏文件、不注入游戏进程**。

### 📋 使用前提（重要）

1. Windows 10/11 64 位，**以管理员身份运行**
2. 战网客户端装在默认路径 `C:\Program Files (x86)\Battle.net`，安装时勾选「**为这台电脑的所有用户安装**」
3. 每个多开位用一个**本地账户**（不支持微软账户/域账户，机制所限）
4. D2R 游戏本体放哪个盘都行

### 🚀 三步上手

**第一步：添加账号。** 「账号管理」→「添加账号」，绑定（或直接新建）一个 Windows 用户、填密码、选个职业头像做标识。

〔图：05-account-manage.jpg —— 账号管理〕
〔图：06-account-modal.jpg —— 添加账号弹窗〕

**第二步：启动。** 回仪表盘点选账号 →「启动游戏」。首次在战网里登录一次，以后就是纯一键。蓝点=战网在线，绿点=D2R在线；有冲突时按钮自动变成琥珀色「强制」模式。

〔图：09-launch-buttons.jpg —— 启动按钮〕
〔图：08-dashboard-list.jpg —— 列表视图（号多的看这个）〕

**第三步：多开。** 选下一个号再点启动，完事。实例锁程序自动处理。

### ⚡ 进阶：序列启动（多号党狂喜）

把固定的开号顺序存成预设 P1–P3，点播放，迷你悬浮窗一路「启动→启动→启动」把所有号拉满。全部开完后点绿色的 **「完成并备份」**，最后一个号的快照也帮你存好。

### ❓ 常见问题

> **Q：会不会封号？**
> A：工具不改游戏文件、不注入、不读写游戏内存，本质上等于"你手动换 Windows 用户开游戏"的自动化。但多开本身请自行斟酌暴雪 ToS，风险自负。

> **Q：为什么必须本地账户？**
> A：跨用户启动用的是 Windows 本地 SAM 认证 API，微软账户的密码在云端、域账户需要域控，都不兼容。

> **Q：多开起不来？**
> A：先「工具→清理互斥锁」；还不行打开「手动修复句柄」看看有没有残留的 `DiabloII Check For Other Instances`，点掉即可。

> **Q：游戏更新报权限错误？**
> A：隔离用户是标准权限，用「工具→修复目录权限」给游戏目录授权一次即可。
