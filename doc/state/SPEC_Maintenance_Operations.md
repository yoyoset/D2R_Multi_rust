# SPEC: Administrative Maintenance & Industrial Reset

This document specifies the high-privilege maintenance commands designed for environment recovery and deep system cleaning.

---

## 1. The "Nuke Reset" Logic (`nuke_reset`)

The `nuke_reset` command is a destructive "歸零" (Return to Zero) operation used for troubleshooting corrupted environmental states.

### 1.1 Atomic Execution Steps
1. **Kill Orchestration**: Triggers `kill_all_related_processes`, targeting `D2R.exe`, `Battle.net.exe`, `Agent.exe`, and `Battle.net Hub`.
2. **Registry/File Purge**: 
    - Deletes `config.json` via `delete_config`.
    - Recursively deletes the `snapshots/` directory.
3. **Cache Sanitation**: Triggers `cleanup_bnet_archives` to clear the Battle.net metadata cache.
4. **Result**: The application state is successfully reverted to "First Boot" conditions.

---

## 2. Archive Sanitation (`cleanup_archives`)

This logic targets the "Bloat" generated by multiple Battle.net instances in protected system folders.
- **Target Path**: `%ProgramData%\Battle.net\Agent\logs` and `Agent.cache`.
- **Algorithm**: Performs a recursive folder walk to remove ephemeral logs and setup artifacts that can cause Code 32 (Sharing Violations) during launch.

---

## 3. Manual State Override

### 3.1 `manual_launch_process`
- **Logic**: Provides a direct conduit to the `create_process_with_logon` bridge.
- **Application**: Allows advanced users to manually test Windows Account credentials without committing them to the permanent account registry.

### 3.2 Snapshot Management
- **`manual_backup_save`**: Triggers a forced `rotate_save` for a specific account ID.
- **`manual_restore_config`**: Triggers a forced `restore_snapshot` for a specific account ID.
